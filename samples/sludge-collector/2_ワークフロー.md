# ワークフロー:汚泥掻き寄せ機

## スタンダードな流れ

1. 運転前点検(目視・音・周囲の安全)
2. 起動と運転状態の確認
3. 運転中の巡視(異音・振動・電流値)
4. 異常時の停止と報告
5. 清掃・給油などの定期整備
6. 点検記録の記入・引き継ぎ

```
運転前点検 → 起動 → 巡視 → (異常あり → 停止・報告) → 整備 → 記録
```

## 関係者

| 役割 | 担当すること | 連絡のタイミング |
|---|---|---|
| 運転担当者 | 日常点検、起動・停止、記録 | 毎日 |
| 保全担当者 | 異常対応、給油、部品交換 | 異常報告を受けたとき |
| 監督者(責任者) | 運転可否の判断、作業許可 | 停止が必要なとき、整備前 |
| 水質管理担当 | 処理水質の確認 | 汚泥浮上など水質に影響が出たとき |
