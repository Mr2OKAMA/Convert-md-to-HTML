# 汚泥掻き寄せ機 業務マニュアル

> 一般的な汚泥掻き寄せ機(沈殿池・沈殿槽のチェーンフライト式/リンク式など)を前提に作成しています。

## 1. 概要・目的(マインドセット)

### 業務の目的
汚泥掻き寄せ機は、沈殿池の底に沈んだ汚泥を、引き抜き口(汚泥ホッパ)へ**途切れなく集め続ける**ための設備です。この機械が止まると、汚泥は底に堆積し、腐敗やガス発生、処理水質の悪化、最悪の場合は機械の過負荷による破損へとつながります。

### 目指すべきゴール
- 汚泥が**滞留せず、一定のペースで**引き抜き口へ集まっている状態
- 異音・振動・発熱などの**小さな変化に早く気づける**状態
- 誰が担当しても同じ品質で点検・記録ができる状態

### 大切にすべき考え方・指針
- **「動いている=正常」ではありません。** 掻き寄せ機は水中で動くため、故障が目に見えません。電流値、音、チェーンの張り、スカムの状態といった「間接的なサイン」から、水の中の状況を想像する姿勢が重要です。
- **「いつもと違う」を大切にする。** 基準値を超えてから対応するのではなく、数値が少し上がってきた時点で気づくことを目指します。記録は、変化を読むための材料です。
- **安全は作業品質の一部。** 急いで早く終わらせるより、確実に止めて、確実にロックして、確実に確認することを優先します。
- **迷ったら止めて相談する方向へ進む。** 無理に動かし続けるより、止めて確認するほうが、結果的に損失が小さくなります。

## 2. 全体フロー(ワークフロー)

```
①作業前準備 → ②運転前点検 → ③運転・監視 → ④定期点検・給油 → ⑤停止・復旧 → ⑥記録・引き継ぎ
```

| ステップ | 内容 | 所要時間の目安 |
|---|---|---|
| ① 作業前準備 | 前回記録の確認、保護具・工具の準備 | 5〜10分 |
| ② 運転前点検 | 外観・水面・駆動部の確認 | 10〜15分 |
| ③ 運転・監視 | 起動、電流・音・動作の確認 | 10〜15分(起動時) |
| ④ 定期点検・給油 | 給油、チェーン・スプロケット・スカムボード点検 | 30〜60分(週次・月次) |
| ⑤ 停止・復旧 | 停止、ロックアウト、異常対応 | 10〜30分 |
| ⑥ 記録・引き継ぎ | 日報記入、申し送り | 5〜10分 |

**日常点検の所要時間の全体目安:約30〜50分**(定期点検を含む日は+30〜60分)

## 3. 詳細手順(オペレーション)

### ① 作業前準備(5〜10分)
- 前回の点検記録・申し送りを確認する
- 保護具を着用する(ヘルメット、安全靴、保護手袋、必要に応じて救命具)
- 工具、グリス、記録用紙、懐中電灯を準備する
- 【要確認】硫化水素・酸欠のおそれがある場所では、ガス検知器を携行する

> ⚠️ **重要ポイント:前回の異常や申し送りの確認漏れは、同じトラブルの再発につながります。** 必ず読んでから現場へ向かってください。

### ② 運転前点検(10〜15分)
- 池・槽内に**人や異物(工具・ロープ・流木など)がない**ことを確認する
- 池の水面状態を確認する(スカムの量、色、異常な泡)
- 駆動装置まわりを確認する
  - 減速機の油量・油漏れ
  - モーターの異音・発熱・異臭
  - ボルトの緩み、カバー類の取付状態
- チェーン・フライト(掻き板)の目視可能範囲に、変形や外れがないか確認する
- 操作盤の表示に**警報が出ていない**ことを確認する

> ⚠️ **ミスが起きやすいポイント**
> - 運転前の「槽内に人・物がないか」確認を省略すること
> - 前回停止時の警報履歴を見落とすこと

### ③ 運転・監視(10〜15分)
1. 操作盤で「手動/自動」の切替状態を確認する
2. 起動する(周囲に声かけをしてから)
3. 起動直後に次の項目を確認する
   - 回転方向、動作が滑らかか
   - **運転電流値**が通常範囲内か(【要確認】定格値・正常範囲)
   - 異音(ガリガリ音、キシミ音、打音)がないか
   - チェーンの揺れ、蛇行、ジャンプがないか
4. 数分間は様子を見て、安定していることを確認する

> ⚠️ **俗人化しやすいポイント:異音・振動の判断**
> 「いつもと違う」の基準は人によって異なります。**異音は録音または写真・動画で記録し、日報に残して**ください。判断に迷ったら、必ず上長に共有します。

### ④ 定期点検・給油(30〜60分/週次・月次)
**【要確認】周期は機種・メーカー指定に従う**

| 項目 | 内容 | 目安周期 |
|---|---|---|
| 給油・グリスアップ | 軸受、スプロケット等 | 週次〜月次 |
| 減速機油 | 油量・汚れの確認、交換 | 月次確認/年次交換 |
| チェーンの張り | たるみ・伸びの確認 | 月次 |
| スプロケット・シュー | 摩耗・欠けの確認 | 月次 |
| スカムボード・スカムスキマー | 変形、固定状態 | 月次 |
| 過負荷保護(トルクリミッター等) | 作動確認 | 【要確認】 |

**手順**
1. **必ず停止し、電源をロックアウト・タグアウト(施錠・表示)する**
2. 給油・清掃・点検を実施する
3. 工具・ウエスなどの**置き忘れがない**ことを確認する
4. カバー類を元に戻し、ロックを解除する
5. 試運転し、異常がないことを確認する

> ⚠️ **ミスが起きやすいポイント**
> - **ロックアウトせずに作業に入ること(重大事故につながります)**
> - 給油の入れすぎ・入れ忘れ
> - 点検後のカバー・ボルト戻し忘れ

### ⑤ 停止・復旧(10〜30分)
**通常停止**
1. 操作盤で停止操作を行う
2. 完全停止を確認する
3. 必要に応じて電源を遮断する

**異常発生時**
1. 異音・過電流・警報などを確認したら、**まず安全に停止する**
2. 状況を記録する(時刻、警報内容、電流値、状況写真)
3. 上長・保全担当へ連絡する
4. 原因(異物かみ込み、チェーン外れ、汚泥の過負荷など)を確認する
5. 復旧後は**低速または短時間で試運転**し、問題がないことを確認する

> ⚠️ **重要:警報をリセットして再起動を繰り返さない。**
> 原因が分からないまま再起動すると、機器破損や二次災害につながります。

### ⑥ 記録・引き継ぎ(5〜10分)
- 日報に次の項目を記入する
  - 点検日時、担当者
  - 運転電流値
  - 異音・異常の有無
  - 給油・部品交換の実施内容
  - 特記事項

## 4. 用語集・補足(グロッサリー・インデックス)

### 用語集
| 用語 | 意味 |
|---|---|
| 汚泥掻き寄せ機 | 沈殿池の底に沈んだ汚泥を、引き抜き口へ集める機械 |
| チェーンフライト式 | チェーンに取り付けた掻き板(フライト)で汚泥を移動させる方式 |
| フライト | 汚泥を掻き寄せる板 |
| スカム | 水面に浮いた浮遊物 |
| スカムスキマー | 水面のスカムを集めて排出する装置 |
| スプロケット | チェーンを駆動・案内する歯車 |
| 汚泥ホッパ | 掻き寄せた汚泥が集まる引き抜き口 |
| ロックアウト・タグアウト | 電源を遮断して施錠・表示し、誤起動を防ぐ安全措置 |
| トルクリミッター | 過負荷時に動力を遮断または保護する装置 |
