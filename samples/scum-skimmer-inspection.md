# スカムスキマー点検手順書

| 項目 | 内容 |
|---|---|
| 文書番号 | SOP-SKM-001 |
| 版数 | 1.0(テスト用) |
| 対象設備 | スカムスキマー(油分・浮遊物除去装置) |
| 点検周期 | 日常:毎日 / 定期:月1回 / 精密:年1回 |

## 1. 目的

スカムスキマーの機能を維持し、浮上スカム(油脂・浮遊物)の回収不良や設備故障を防止する。

## 2. 適用範囲

排水処理槽、沈殿槽、油水分離槽などに設置されたスカムスキマー(回転パイプ式・ベルト式・堰式)。

## 3. 安全上の注意

> **警告**:点検前に必ず電源を遮断し、ロックアウト・タグアウトを実施すること。

- 保護手袋、保護メガネ、長靴を着用する
- 槽内作業は2名以上で行い、転落防止措置を講じる
- 硫化水素などの有毒ガスに注意し、必要に応じてガス検知を行う
- 回転部・可動部に手を近づけない

## 4. 準備するもの

- 点検記録票
- 懐中電灯
- スケール(スカム回収用ヘラ)
- グリス、潤滑油
- 工具一式(レンチ、ドライバー)
- 清掃用具・バケツ

## 5. 日常点検(毎日)

- [ ] 異音・異常振動がない
- [ ] スカムが正常に回収されている
- [ ] 槽内に浮遊物が溜まっていない
- [ ] 駆動モーターが異常発熱していない
- [ ] 回収槽が満杯になっていない

## 6. 定期点検(月1回)

### 6.1 手順

1. 運転を停止し、電源を遮断する(ロックアウト・タグアウト)
2. 外観を点検する(変形、腐食、破損、ボルトの緩み)
3. スキマー本体・ゴムブレードの摩耗、劣化を確認する
4. 駆動部(モーター、減速機、チェーン/ベルト)を点検する
5. 給油・グリスアップを行う
6. 回収配管・排出口の詰まりを清掃する
7. 電源を復旧し、試運転を行う(5分以上)
8. 結果を点検記録票に記入する

### 6.2 判定基準

| 点検箇所 | 判定基準 | 処置 |
|---|---|---|
| ゴムブレード | 摩耗が5mm以下 | 交換 |
| 駆動チェーン/ベルト | 伸び・ひび割れなし | 調整または交換 |
| モーター温度 | 周囲温度+40℃以下 | 異常時は点検依頼 |
| 固定ボルト | 緩みなし | 増し締め |
| 回収配管 | 詰まりなし | 清掃 |

## 7. 精密点検(年1回)

1. 減速機のオイル交換
2. ベアリングの状態確認・交換
3. モーターの絶縁抵抗測定(目安:1MΩ以上)
4. 腐食部の補修・塗装
5. 制御盤・タイマー・リミットスイッチの動作確認

```text
絶縁抵抗の測定例
測定電圧: DC500V
測定値  : 5.2 MΩ  → 合格(1MΩ以上)
```

## 8. 異常時の対応

| 症状 | 想定原因 | 対応 |
|---|---|---|
| スカムが回収されない | ブレード摩耗、水位不適正 | ブレード交換、水位調整 |
| 異音がする | ベアリング劣化、異物噛み込み | 停止して点検 |
| 動かない | 電源異常、モーター故障 | 電源確認、保全担当へ連絡 |

## 9. 記録

点検結果は点検記録票に記入し、**3年間**保管する。
